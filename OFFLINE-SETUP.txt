UPDATE STEPS
1. Before uploading, open the current MOS Project Monitor and export the COMPLETE JSON backup.
2. Keep the SAME repository and GitHub Pages URL. Replace the existing index.html
   and add the five companion files above; commit all six together.
3. While online, open your GitHub Pages app in Safari and wait until the top banner says "Offline ready".
4. Add to iPhone Home Screen. IMPORTANT: open the newly installed Home Screen app online at least once
   and confirm "Offline ready" inside that app. On iOS, Home Screen storage can differ from Safari.
5. Switch on Airplane Mode and open the Home Screen app to test offline operation.
6. Keep exporting complete JSON backups to Files/iCloud Drive. Cache/storage can be cleared by iOS.

IMPORTANT LIMITATION
No website, including GitHub Pages, can load at a brand-new URL with no internet BEFORE
it has been downloaded or otherwise installed onto that device. This release ensures
subsequent launches are offline after first successful online installation and precache.
